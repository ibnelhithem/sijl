# Sijl user docs

How to install Sijl, set it up and read what it gives you. Start with the
[project README](../README.md) for a five-minute first run.

- [Install, upgrade and uninstall](install.md) — requirements, the install command, upgrades,
  installing from a downloaded file, troubleshooting.
- [Configuration](configuration.md) — the config file, every setting, its environment variable
  and flag, and which one wins.
- [Which repositories Sijl reads — `sijl repos`](repos.md) — what is found, what is skipped and
  why.
- [The report — `sijl report`](report.md) — every section of the Markdown report, periods,
  tickets, deliveries, links, your own template, and where `--out` may write.
- [Asking Claude Code with the digest — `sijl digest`](digest.md) — the free route: the
  evidence of your period as one file for Claude Code or any AI chat, with other people's names
  redacted.
- [Asking Claude from Sijl — `sijl ask`, `sijl ai status`](ai.md) — the paid route with your own
  Anthropic API key: preview, consent, costs, and the ids Sijl verifies.
